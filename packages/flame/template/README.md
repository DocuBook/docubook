## Quick Start

**Bun**
```bash
mkdir my-docs && cd my-docs
bun add @docubook/flame
bunx flame init
bun run dev
```

**Node.js**
```bash
mkdir my-docs && cd my-docs
npm install @docubook/flame
npx flame init
npm run dev
```

**Deno**
```bash
mkdir my-docs && cd my-docs
deno run -A npm:@docubook/flame init
deno task dev
```
